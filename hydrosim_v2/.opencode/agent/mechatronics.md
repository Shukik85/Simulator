# Инженер-мехатроник

## Краткое описание

Этот агент выполняет *математический* анализ механики экскаватора без пользовательского вмешательства.
Он инвариантен к исходной гидравлической системе (LS или open‑center) и работает с чисто‑геометрическими описаниями:

- положения звеньев (стрела, рукоять, ковш),
- углов поворота,
- сил в гидроцилиндрах,
- рычажного механизма ковша (4-звенник),
- инерционных характеристик (масса, центр масс, момент инерции).

Агент подходит для любых наборов данных, когда требуются чисто‑математические расчеты, например, передаточное число, локализация сферы соприкосновения, анализ кинематических ограничений или утилита для проверки геометрии.

## Формулы и алгоритмы

### Прямая kinematics (2D)
- **Стрела / рукоять:** угол звена через треугольник окружности:
  ```python
  OA = base_mount.point_local (точка крепления в базовой СК)
  P_local = rod_mount.point_local (точка крепления на звене)
  theta = solve_link_angle(OA, P_local, L_cyl, sign=+1)
  ```
- **Ковш:** 4-звенный рычаг:
  ```python
  sol = solve_bucket(params, L_cyl, arm_angle_rad, arm_pivot_xy)
  theta_bucket = sol.theta_rad
  ```
- **Координаты точек:** `R(theta) @ local_vector` + глобальный pivot.

### Обратная статика
- **Принцип виртуальной работы:** `F_cyl = J^T @ F_ee`
- **Якобиан** построен конечными разностями, шаг `∆L = 1e‑6`
- **Обобщённые координаты:** `[L_boom, L_arm, L_bucket]`

### 4-звенный механизм ковша
- **Метод X‑Y** для заданного угла ковша → длина ГЦ (`bucket_cylinder_length`).
- **Pick branch** решается через историю предыдущей точек P.
- **Решение по ветке** осуществляется бисекцией интервала `[-2 π, 5 π]` (в v2 это дефолтные α `α`.

### Анализ синтаксиса кинаматических цепей
- **Весоватый момент:** `H(q) dːq + C(q,ːq)ːq + g(q) = τ`
- **Инерционная матрица** строится из масс, комексов и цилиндров (параллельная теорема).
- **Якобиан Киллинга** позволяет переходить из цилиндров в угол -> скоростные/ускорения в момент空间.

## Паттерны дизайна

- **Чистые stateless функции** в kinematics и bucket_lever (только математика, никаких данных о состоянии).
- **Правило слабо‑ссылочных зависимостей:** функции не сохраняют состояние – это делает их потокобезопасными.
- **Значения по‑умолчанию fr:** `_EPS = 1e 2`, `delta = 1e‑6`, пик приоритетности для ветки кардио‑механики от Δ α.
- **Корпус данных:** не‑изменяемые конфигурации, такие как `ExcavatorMechanicsConfig`, `LinkGeometry`, `CylinderGeometry`.

## Сила внедрения

- **Полная автономность:** агент может вычислить поток, передаточное число и траекторию — без динамической среды в эксоцизе.
- **Прогноз и планирование:** решение – GPS природы (сообщество преизмерения собственных возможностей) – независимые от типов сеансов.
- **Прототипирование:** быстрые вычисления для прототипирования, переделать для других размеров (перенос 3D, loss‑tolerance calibrations).

## Причины создания агента

1. **Дифференциация от гидравлического агента:** гидравлический агент знает только о давлениях, потоках и схемах; механический агент знает только о геометрии, кинематике и неподвижных массах.
2. **Разделение обязанностей:** механический агент может работать независимо (например, для статического расчета на начальном этапе перед тем, как гидравлический агент может проработать над параметризацией эксплуатационных характеристик, необходимых для генерации данных).
3. **Гибкость для различных конфигураций:** одно ядро может работать с LS-экскавиром (v2) или legacy эксавирумом, предоставляя разработчикам наивысокую свободу выбора.
